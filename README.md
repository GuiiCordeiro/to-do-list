# To-Do List

Uma aplicação simples de lista de tarefas, desenvolvida como projeto de estudo para praticar **HTML, CSS e JavaScript**.

O objetivo foi colocar em prática conceitos de desenvolvimento web, principalmente manipulação do DOM, eventos e armazenamento de dados no navegador.

## Funcionalidades

- Adicionar novas tarefas.
- Excluir tarefas da lista.
- Adicionar tarefas pressionando Enter.
- Impedir o cadastro de tarefas vazias.
- Salvar tarefas no `localStorage`, mantendo os dados mesmo após atualizar a página.

## Tecnologias utilizadas

- **HTML5**
- **CSS3** 
- **JavaScript**

## Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` no navegador.


## Objetivo do projeto

Este projeto foi desenvolvido para praticar os fundamentos de HTML, CSS e JavaScript, especialmente a interação com elementos da página e o uso de eventos para criar funcionalidades dinâmicas.
